❓ 如何取得 GitHub Token (PAT)？
  1. 登入 GitHub ➔ 點右上角頭像 ➔ Settings
  2. 左側滾到底部點 Developer settings ➔ Personal access tokens ➔ Tokens (classic)
  3. 點 Generate new token (classic)
  4. Note 填寫 photo-journal，勾選 repo（完整倉庫權限）
  5. 點最下方綠色按鈕 Generate token，複製金鑰貼至此處。
    （金鑰僅保存在本機瀏覽器，絕不上傳他人伺服器）
